Path sums, circulation, and statistical geodesics

Investigation 8.1

Take a path \(A\to B\to C\) with scalar values \(\phi(A)=1\), \(\phi(B)=4\), and \(\phi(C)=2\).

  1. Calculate the two gradient edge values.

  2. Add them.

  3. Compare with \(\phi(C)-\phi(A)\).

Investigation 8.2

On a directed triangle \(A\to B\to C\to A\), assign each oriented edge value \(1\).

  1. Calculate the circulation.

  2. Determine whether this edge field could be the gradient of a scalar potential.

  3. Justify using telescoping.

Investigation 8.3

Consider count states \(a=(4,1,1)\) and \(b=(1,2,3)\) with \(N=6\).

  1. Compute \(\sum_i|a_i-b_i|\).

  2. Find the minimum number of token transfers.

  3. Construct an explicit route attaining that minimum.

Investigation 8.4

Choose two different routes between the same endpoints in the six-token triangle.

  1. Calculate a scalar potential such as entropy at every vertex of both routes.

  2. Sum the gradient differences.

  3. Compare the unsigned cumulative changes \(\sum|\Delta H|\).

  4. Explain why the latter can depend on the route.

Investigation 8.5

Use Fisher–Rao edge weights for two short legal routes between the same probability states.

  1. Compute and add the edge distances with a calculator.

  2. Find the exact Fisher–Rao distance between endpoints.

  3. Check that neither route length is smaller than the endpoint distance.
